RF Link Budget

Follow the power from transmitter to receiver and check the design margin at every stage.

01 Transmitter

Transmitter → TX cable → TX antenna. Include connectors and adapters in the cable loss. 0 dBd = 2.15 dBi.

02 Path

Additional path losses

Antenna alignment

Calculate polarization mismatch

Circular antennas use the same sense on both ends for a matched link (RHCP to RHCP). An ideal circular antenna has a 0 dB axial ratio; real ones are typically 0.5–3 dB. For a satellite whose linear antenna rotates with its attitude, or a linear wave rotated by the ionosphere (Faraday rotation), the angle is unknown.

Formulas

PLF=12[1+cTcR+eTeRcos2ψ],L=−10log10PLF
e=r2−1r2+1,c=2rr2+1,r=±10AR/20

r is the axial ratio as a voltage ratio: + for right-hand, − for left-hand; a linear antenna is the limit r → ∞, so e = 1 and c = 0. ψ is the angle between the polarizations; an unknown angle uses cos 2ψ = 0 for the average and cos 2ψ = −1 for the worst case.

Special cases

Linear to linear (45° gives 3 dB; 90° gives no coupling):

L=−20log10|cosψ|

Linear to circular: 3 dB. Ideal circular with the same sense: 0 dB; with opposite senses: no coupling.

Calculate pointing loss

Leave the pointing error blank for an antenna whose gain above already applies in the direction of the other end, such as a wide-beam antenna read from its pattern. The losses of both ends are added.

L=12(θeθ3dB)2,Ltotal=LTX+LRX

θe: pointing error; θ3dB: half-power beamwidth. A main-beam approximation, for θe up to about θ3dB/2.

Estimate building entry loss (ITU-R P.2109)

The loss varies with the position in the building, so it is given for a percentage of locations: 50 % is the median, and a higher percentage covers more of the building. The elevation is 0° on terrestrial paths and the shared elevation on Earth–space paths.

Formulas

LBEL=10log10(100.1A+100.1B+100.1C),A=F−1(P)σ1+μ1,B=F−1(P)σ2+μ2,C=−3
μ1=r+slog10f+t(log10f)2+0.212|θ|,μ2=w+xlog10f,σ1=u+vlog10f,σ2=y+zlog10f

F−1: inverse normal distribution; P: probability that the loss is not exceeded; f in GHz; θ: elevation at the façade; r … z: P.2109 Table 1 coefficients for the building type.

Estimate diffraction loss (ITU-R P.526)

One obstacle treated as a knife edge. Terrestrial paths use the antenna altitudes under the shared conditions, the obstacle's altitude and distance, and the Earth's bulge for the factor k. Earth–space paths: an obstacle near the ground antenna, such as a building or a ridge.

Formulas

ν=h2λ(1d1+1d2),J(ν)=6.9+20log10((ν−0.1)2+1+ν−0.1)

Other

Scintillation and multipath vary with time, so they are usually covered by the required margin; enter them here only if the margin does not include them, so they are not counted twice.

Losses between the two antennas beyond free space. Equipment losses such as connectors belong in the TX and RX cable losses. Enter 0 for any that do not apply; their sum is applied as one stage.

03 Receiver

RX antenna → cable → amplifier → receiver, or the amplifier first for a masthead LNA. Include connectors and adapters in the cable loss. Enter 0 dB gain if there is no amplifier. The position changes the system noise figure, not the received power.

04 Requirements

Sensitivity is referenced to the receiver input, after the RX amplifier and cable. The EIRP limit is optional, e.g. the regulatory limit for the band.

Noise and SNR

Formulas

N=−173.975+10log10Tsys290K+10log10BdBm
Tsys=Ta+290K·(F−1),F=10NF/10
SNR=C−N

B: bandwidth; Ta: antenna noise temperature; C: power at the RX antenna output. With Ta = 290 K, N = −173.975 + 10 log₁₀ B + NF.

The total system NF must include the RX cable, amplifier and receiver, referred to the RX antenna output; do not enter the amplifier NF alone. Tick the box to derive it with the Friis formula, treating the RX cable as a passive loss at 290 K (NF = loss). Leave the antenna noise temperature blank for the 290 K reference; set it for antennas that see a colder or hotter scene, such as a satellite ground station facing the sky. The equivalent sensitivity is the receiver input level that just meets the required SNR, for comparison with the datasheet value.

Data Rate and Eb/N₀

Formulas

C/N0=C−(−173.975+10log10Tsys290K)dB-Hz
Eb/N0=C/N0−10log10Rb
M=Eb/N0−(Eb/N0)req−Limpl,Rb,max=10(C/N0−(Eb/N0)req−Limpl)/10

Rb: data rate (bit/s); Limpl: implementation loss; M: Eb/N₀ margin.

Uses the total system noise figure and antenna noise temperature above. The required Eb/N₀ depends on the modulation, coding and target bit error rate: for example, uncoded BPSK or QPSK needs about 9.6 dB for a BER of 10⁻⁵. Implementation loss covers demodulator and filter imperfections.
